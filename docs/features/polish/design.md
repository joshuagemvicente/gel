# U9 · Polish & motion — Design

Extends [app-shell/design.md](../app-shell/design.md). New tokens below are added there once built.

## Motion tokens (`Motion` in `Theme.swift`)

| Token | SwiftUI | Use |
| --- | --- | --- |
| `snappy` | spring response 0.28, damping 1.0 | selection, hover, press, small state flips |
| `smooth` | spring response 0.42, damping 1.0 | content entering, panels, module switch, heights |
| `pop` | spring response 0.35, damping 0.72 | success marks, toggles turning on, chips arriving |
| `stagger` | 35 ms per item, max 8 items | lists and chip rows arriving |
| Reduce Motion | `.easeOut(duration: 0.15)`, opacity only | replaces every token; offsets/scales become 0/1, loops stop |

Press feedback: scale 0.97 on mouse-down (snappy). Hover: fill `hairline` at 50% (snappy). No animation is longer than 450 ms except the leak countdown bar (12 s, linear, it *is* a timer).

## Brand

**Gel mark (`GelDrop` Shape):** a teardrop, pointed top, full round base, drawn as one Bézier path in a unit square (reused for the icon, the menu bar and in-app). In-app rendering: vertical gradient `#4FC48A → #1F7A4D` (dark: `#5CD49A → #2A8F5C`), an inner highlight (white 45%, ellipse at upper-left third), a 1 pt inner rim. States:

| State | Behaviour |
| --- | --- |
| still | static |
| thinking (launcher waiting/transcribing/streaming only) | breathes: scale 0.98 → 1.06 with a slight squash (x 1.03 / y 0.96), 0.9 s ease-in-out, `repeatForever` autoreverse |
| listening | scale follows the mic level (1 → 1.18), snappy |

Reduce Motion: thinking = opacity 1 ↔ 0.6 cross-fade, listening = static.

**App icon:** macOS squircle (824 pt body in a 1024 canvas, standard 100 pt margin, continuous corners), warm off-white gradient `#FBF9F4 → #EDE7DB` with a 1 px top rim light, a large glossy Gel drop centred slightly low, a soft contact shadow under the drop, and the system-style squircle shadow. Generated by `scripts/make_icon.swift` → `Gel/Gel/Assets.xcassets/AppIcon.appiconset` (16–1024 @1x/@2x).

**Menu bar:** the same drop path as a 16 pt template image (outline when normal; filled while the launcher is answering is out of scope). Cloud/warning states keep their SF Symbols.

## Shell

> **Shipped deviation (D-047):** the main window is fully static. Its hosting view crashes AppKit when any SwiftUI animation is in flight during a constraints pass (reproduced with a real click Home → Library). So the sliding selection, module transition, staggered entries, rolling numbers, symbol bounces and hover/press animations below are **not** in the main window. Hover and selection states still change, instantly. Motion lives in the launcher and leak-overlay panels, and in onboarding and the Redact sheet (sheets).

- **Sidebar:** brand row = `GelDrop` 20 pt + "Gel" 20 semibold, tracking −0.3. Selection is one accent-soft pill that **slides** between rows (`matchedGeometryEffect`, snappy). Selected icon uses the `.fill` symbol variant in accent. Hover fill on other rows. Rows 32 pt tall.
- **Status footer:** dot with a 3 pt halo of its own colour at 25% (static; dimmed while `checking`). While indexing, the status line reads "Reading 12 of 58" and a 2 pt accent bar under it fades in. The footer's layout never changes per progress tick (D-047).
- **No continuous animation in the main window** (no pulses, no breathing mark): it loops AppKit's constraint pass during layout (D-047).
- **Module switch:** incoming view fades in and rises 8 pt (smooth); outgoing fades out (snappy). Keyed by module.
- **Module header:** title 26 semibold, tracking −0.4, plus a 13 pt `textSecondary` subtitle:
  Home "Good morning/afternoon/evening · <weekday, month day>" · History "<n> questions · every answer keeps its sources" · Library "<n> files · read on this Mac" · Redactions "Counts only. Gel never stores what you copied." · Settings "Everything here stays on this Mac."

## Buttons (`GelButtonStyle`)

| Kind | Look |
| --- | --- |
| `.primary` | accent fill, white 13 pt medium text, 8 pt radius, min height 28, horizontal padding 14; hover +6% brightness; press 0.97 |
| `.secondary` | card fill, hairline border, textPrimary |
| disabled | 40% opacity, no hover |

The accent fill stays when the window is not key (fixes grey CTAs). Used for: onboarding Continue/Done, Redact N files, Export report, Paste redacted, Choose a folder, Retry.

## Launcher

- **Appear:** panel fades in while content scales 0.98 → 1 (smooth, ~160 ms). Disappear: fade 100 ms (unchanged).
- **Leading glyph:** `GelDrop` 18 pt — still when idle, thinking while transcribing/waiting/streaming, listening while recording. Replaces the magnifying glass and spinner.
- **Waiting:** shimmer rebuilt as three skeleton lines (100%, 86%, 58%) with a gradient highlight clipped to each line, sweeping left → right (1.3 s linear `repeatForever`); Reduce Motion = static lines at 60% opacity.
- **Answer area:** appears with fade + 4 pt rise (smooth). The panel frame resizes instantly, top edge fixed (no frame animation, D-047); streaming tokens don't animate the text itself. Model `- ` list lines render as `•` bullets.
- **Citations:** when the answer is done, chips arrive one by one (pop, scale 0.9 → 1 + fade, 35 ms stagger). Chip hover: accent-soft fill and accent border; the number gets an accent circle (`1` in a 16 pt accent circle + file label).
- **Provider badge:** leading glyph `cpu` (local) / `cloud` (cloud), fades in after the chips.
- **Error:** one horizontal shake (6 pt, 3 oscillations, 0.35 s) + `exclamationmark.circle.fill` in danger. Reduce Motion: no shake.
- **Recording:** mic shows a soft accent ring that scales with level; level-meter bars use snappy springs.

## Leak overlay

```
┌───────────────────────────────────────────────┐
│ (⛨)  Gel caught a leak · Chrome            ✕  │   shield in a danger-soft circle, bounces once
│      This would leak: 2 names, 1 TIN, 1 phone  │
│      [ Paste redacted  ⌥⌘V ]   Ignore           │   primary + quiet
│ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬────────────────── │   2 pt bar drains over the 12 s auto-dismiss
└───────────────────────────────────────────────┘
```

- 380 pt wide, 14 pt radius, card fill, hairline border, a 3 pt danger accent on the leading edge.
- Enters by sliding in from the right 40 pt + fade (smooth); leaves the same way (ease-in 0.2 s). The slide happens inside SwiftUI; the panel frame is fixed and the card draws its own shadow (D-047). Reduce Motion: fade.
- Blocked mode: the secondary slot reads "Blocked by <org>" with a lock glyph.

## Home

- Stat cards: a 26 pt icon chip (accent-soft) — `lock.shield` kept on device, `hand.raised` leaks caught, `cpu` answered locally — then the serif number, then the label. Numbers roll with `.contentTransition(.numericText())` when they change.
- On first appear, the four cards rise 10 pt and fade in with stagger.
- Index card: when indexing, a 4 pt accent progress bar with "Reading 12 of 58".
- TODAY rows: leading 24 pt icon chip per kind — question `text.bubble` (accent), redaction `eye.slash` (textSecondary), leak `exclamationmark.shield` (danger). New rows insert at the top with move + fade.

## Onboarding

- Steps push horizontally: forward = new step enters from the right (24 pt + fade), back = from the left. Smooth.
- Page indicator: current step is a 18 × 7 pt capsule, others 7 pt dots; the capsule slides/widens (snappy).
- Step 0 hero: `GelDrop` 56 pt drops in once (from −16 pt, pop). Title "Gel" 28 semibold.
- Choice cards: hover lift (shadow), selected = accent border + a check badge in the top-right that pops in.
- Indexing step: static drop, accent progress bar (6 pt, rounded, not animated per tick), count and current file name as plain text; when finished, `checkmark.circle.fill` 40 pt in accent bounces once and reads "<n> files ready".

## Library, History, Redact sheet, Settings

- **Library:** row hover; the viewer cross-fades when the shown document changes; under the viewer, a citation shows as an accent pill "Cited passage · page 2 of 3"; PDF background follows `canvas` (dark-mode fix).
- **History:** detail cross-fades on selection; "What was sent" content in a canvas-filled monospace block with a `lock.open` caption.
- **Redact sheet:** scanning shows each file with a spinner that turns into a check; phases cross-fade; done = 40 pt check that bounces + "Saved n redacted files. Originals are unchanged."
- **Settings:** each section title gets a 24 pt icon chip: folder `folder`, packs `square.stack.3d.up`, models `cpu`, cloud `cloud`, hotkeys `command`, permissions `hand.raised`, policy `building.2`.
- **Empty states:** symbol inside a 56 pt accent-soft circle.
