# S2 · X post — Spec

**Goal:** `docs/deliverables/x-post/post.md` holds a ready-to-paste X post that goes out with the S3 video, satisfies the hackathon's post requirement and makes a stranger want to watch.

## Content of `post.md`

1. **Main post** (≤ 280 characters as X counts them):
   - Line 1: the hook, what Gel does in plain words, with the local/offline angle.
   - Line 2: one concrete thing the video shows (e.g. catching an ID number before it's pasted into ChatGPT).
   - Line 3: tags: the verified Devin and Cognition handles, `#AppBuildersPH`, and the repo link.
2. **Short variant** (≤ 240 characters) in case of length problems.
3. **Alt text** for the video (≤ 1,000 characters), describing what happens on screen.
4. **Pre-post checklist:** video file name, handles verified, account public, character count shown.
5. A line where the user pastes the **post URL** after posting.

## Acceptance criteria

- [ ] The main post is ≤ 280 characters by X's count, including tags and link.
- [ ] It tags the verified official Devin and Cognition accounts and includes `#AppBuildersPH`.
- [ ] Every claim in it is visible in the attached S3 video; no numbers that aren't measured.
- [ ] The posted URL opens in a logged-out browser and the video plays.
- [ ] The URL is copied into `post.md` and into S1's `answers.md`.
