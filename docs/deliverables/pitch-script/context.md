# S4 · Pitch script — Context

## Why it exists

Finalists get **5 minutes to pitch and demo live + 3 minutes of judge Q&A**. The user presents solo, in person, after a night of building, so the script has to carry them.

## Where it sits

- **Upstream:** demo beats in `docs/project/demo-and-submission.md`; product story in `docs/project/product.md`; judging weights in `docs/project/context.md`; what's built (each feature's `tasks.md`).
- **Downstream:** [S5 judge-qa](../judge-qa/spec.md) picks up where the script stops; [S6 run sheet](../demo-day-runsheet/spec.md) sets the stage state the script assumes; [S7](../peoples-choice/spec.md) supplies the closing ask.
- **Owner:** Claude writes `script.md`; the user rehearses and delivers.

## Current state

The beat list in `demo-and-submission.md` (problem ~40 s, HR demo ~3 min, consumer reveal 20 s, why local + business ~60 s) exists; no spoken script yet.

## Facts and gotchas

- Judges: 10, announced on the day. Mixed technical and business audience; sponsors include AMD, Cognition, WhiteCloak, Tutorials Dojo, PDAX.
- Pitching starts 13:40; finalists are announced at 13:00, so the final rehearsal is in the morning.
- The venue's Wi-Fi is irrelevant to the core demo (Wi-Fi is off), but the leak beat needs chatgpt.com loaded: load it **before** turning Wi-Fi off, or turn Wi-Fi on for that beat as scripted.
- Projector resolution can make the top-center launcher small; the run sheet's AV check covers zoom.
- Speaking language: English with the Taglish demo question (the user can switch to Taglish asides if the room is local; mark them optional).
